# Archive — historical / superseded docs

These are inception-era planning documents (mostly early July 2026) kept for
history. **They are NOT the current source of truth** and may contradict what
was actually built. Do not treat anything here as authoritative.

For current state, read (in this order):

1. `docs/ai/next-session.md` — what's done / in progress / next steps
2. `docs/ai/current-focus.md` — the active milestone
3. `docs/ai/decisions.md` — settled decisions
4. `docs/ai/ux-backlog.md` — the feature/polish backlog
5. `docs/execution-plan.md` — the 50-user ops-readiness plan (complete)

  as "why was this built" history; superseded by the shipped app.

- `QUICKSTART.md` — early quick-start notes (see the root `README.md` instead).
- `PLAN-part6.md` — a Part 6 implementation plan.
- `ENGINEERING_OS.md` — link stub to the engineering-os system.
- `HANDOFF.md` — retired session-handoff tombstone (now `docs/ai/next-session.md`).
- `TODO.md` — old TODO list, superseded by `docs/ai/ux-backlog.md`.
